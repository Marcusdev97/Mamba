# Mamba 中央 Server（只读）

让**另一台电脑在同一个 Wi-Fi 下**看这台主机的客户对话。

只能看，不能改，也不会发任何 WhatsApp 讯息。

---

## 怎么开（主机这台）

```bash
node hub-server/server.mjs
```

或者直接双击 `hub-server/start.command`。

开起来之后终端机会印出网址，长这样：

```
在另一台电脑的浏览器打开：

  http://192.168.68.50:8899/?key=4KIADPxguQ9i
```

## 另一台电脑怎么连

把上面那条**完整网址**（包含 `?key=...`）贴进浏览器就好。不用装任何东西，手机
平板也可以，只要在同一个 Wi-Fi 下。

网址存成书签就不用每次抄了 —— 存取码不会变，除非你自己换掉。

---

## 画面上有什么

- **四个数字**：等你回 / 有回复的客户 / 客户总数 / 客户讯息数
- **等你回**：最后一句是客户说的，也就是球还在你这边
- **全部回过的**：所有回过你的客户
- 点任何一个客户 → 看完整对话（绿色是你发的，深色是客户说的）

列表每 60 秒自动刷新一次。

## 关于安全

**存取码**：第一次启动会产生一组，存在 `hub-server/.access-token`，权限 `0600`
（只有这台电脑的你读得到），而且不会进 git。

要换一组（旧网址立刻失效）：

```bash
node hub-server/server.mjs --new-token
```

**要知道的事**：这是区域网路上的 HTTP，不是加密连线。存取码挡得住「同一个 Wi-Fi
的人乱扫 port 就翻到客户资料」，但挡不住有心人在同一个网路上监听封包。

所以：

- **不要在咖啡厅、机场、饭店这种公共 Wi-Fi 开。** 在家里或办公室自己的 Wi-Fi 才开。
- 不用的时候就关掉（Control-C）。
- 要更安全的话跟我说，改走 Tailscale —— 只有你自己的装置连得到，而且是加密的，
  换网路也不用重设。

**写不了东西**：开资料库时钉死了 sqlite3 的 `-readonly`，就算程式有 bug 也弄不坏
资料；POST 之类的请求一律回 405。

---

## 换 port

预设 8899。被占用的话：

```bash
node hub-server/server.mjs --port=9100
```

---

## 资料从哪来

直接读 `campaign-data/mamba.sqlite` —— 跟 Mamba 本体同一个资料库，所以看到的
永远是最新的，不用同步、不用汇出。

主机那台的 Mamba 不用开着也能看（资料库是档案），但要收新的客户回复，Mamba
本体还是要跑。
